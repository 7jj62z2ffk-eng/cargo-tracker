使用说明

这是什么：本地自托管的货物跟踪工具，零外部依赖，数据存在本机 cargo.db，可长期使用、不上传第三方。

怎么启动：在 cargo-tracker/ 目录执行 python3 app.py（默认端口 8765），浏览器打开 http://127.0.0.1:8765。停止按 Ctrl+C。

怎么查：

  • 快速查询：输入箱号/提单/订舱号直接查，不入库。
  • 登记货物：填箱号+类型（+客户/港口/备注），「登记并跟踪」会拉实时状态并缓存轨迹；列表里点任意行看时间线。
  • 箱号前 4 位会自动识别船公司（Maersk / MSC / CMA CGM / COSCO / Hapag-Lloyd / ZIM 等）。

数据来源：TrackingMCP 公开端点（229 家船公司 DCSA 标准数据）。「官网」按钮直跳船司官网跟踪页，搜索按钮兜底。

注：公开端点有速率限制；需要组合跟踪、滞箱费预警、历史留存建议申请免费 key 填入设置。
